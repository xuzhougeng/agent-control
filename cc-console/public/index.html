Linux Guide

按下面 4 步操作：先拿凭证，再在 Tenant Panel 生成 Token，最后安装并连接 Agent。
1) 获取凭证（当前页面）
  • 先记录 TENANT_ID（Account 区域）与 TENANT_TOKEN（Tenant Token 区域）。
  • TENANT_TOKEN 仅用于登录 Tenant Panel，不用于 Agent 连接。
2) 配置面板（Tenant Panel）
  • 点击上方 Open Tenant Panel，用 TENANT_TOKEN 登录。
  • 在面板中创建 UI Token（网页查看/操作）与 Agent Token（Agent 连中心服务）。
  • 必须区分：UI Token 不能用于 -agent-token，Agent Token 才能给 Agent 启动参数使用。
3) 安装与启动（不要用 Quick Start）
3.1 无 Claude 时（用 bash 作为执行器）
curl -fL -o cc-agent https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-agent-linux-amd64
chmod +x cc-agent

./cc-agent \
  -control-url wss://106.54.201.18/ws/agent \
  -tls-skip-verify \
  -agent-token <AGENT_TOKEN> \
  -server-id <SERVER_ID> \
  -allow-root "$HOME" \
  -claude-path "$(which bash)"
3.2 已安装 Claude 时（推荐）
curl -fL -o cc-agent https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-agent-linux-amd64
curl -fL -o cc-chat-claude https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-chat-claude-linux-amd64
chmod +x cc-agent cc-chat-claude

./cc-agent \
  -control-url wss://106.54.201.18/ws/agent \
  -tls-skip-verify \
  -agent-token <AGENT_TOKEN> \
  -server-id <SERVER_ID> \
  -allow-root "$HOME" \
  -chat-worker "$PWD/cc-chat-claude" \
  -claude-path "$(which claude)"
3.3 参数说明（重点）
  • 必填：-control-url、-agent-token、-server-id。
  • 按需：-allow-root（允许访问目录）、-chat-worker（启用 Claude worker）、-claude-path（可执行程序路径）。
  • 证书提示：-tls-skip-verify 仅在自签名/证书不完整时使用；生产环境建议配好证书后去掉。
  • 不要填错：不要把 TENANT_TOKEN 或 UI Token 填到 -agent-token。
  • 避免冲突：-server-id 需要全局唯一，重复名称会导致管理混淆。
4) 界面连接与会话使用
  • 网页端进入左侧 Sessions。
  • 点击 Workspace Task，先创建一个 Session。
  • 若不创建 Session，页面不会显示可用会话内容（这是正常现象）。
Windows 重点说明
  • Windows 端目前仅支持 Chat 模式。
  • 不支持 PTY（终端模拟），因此无法像 Linux 一样提供交互式 shell 会话。
  • 如果需要终端类操作，请优先使用 Linux/macOS Agent。
Follow these 4 steps: get credentials, create tokens in Tenant Panel, then install and connect your agent.
1) Get credentials (on this page)
  • Record TENANT_ID (Account section) and TENANT_TOKEN (Tenant Token section).
  • TENANT_TOKEN is for Tenant Panel sign-in only, not for agent connection.
2) Configure in Tenant Panel
  • Click Open Tenant Panel above and sign in with TENANT_TOKEN.
  • Create both UI Token (web access) and Agent Token (agent to control server).
  • Important: keep them separate. UI Token cannot be used as -agent-token.
3) Install and start (do not use Quick Start)
3.1 Without Claude (use bash worker)
curl -fL -o cc-agent https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-agent-linux-amd64
chmod +x cc-agent

./cc-agent \
  -control-url wss://106.54.201.18/ws/agent \
  -tls-skip-verify \
  -agent-token <AGENT_TOKEN> \
  -server-id <SERVER_ID> \
  -allow-root "$HOME" \
  -claude-path "$(which bash)"
3.2 With Claude installed (recommended)
curl -fL -o cc-agent https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-agent-linux-amd64
curl -fL -o cc-chat-claude https://github.com/xuzhougeng/agent-control/releases/latest/download/cc-chat-claude-linux-amd64
chmod +x cc-agent cc-chat-claude

./cc-agent \
  -control-url wss://106.54.201.18/ws/agent \
  -tls-skip-verify \
  -agent-token <AGENT_TOKEN> \
  -server-id <SERVER_ID> \
  -allow-root "$HOME" \
  -chat-worker "$PWD/cc-chat-claude" \
  -claude-path "$(which claude)"
3.3 Parameter notes (important)
  • Required: -control-url, -agent-token, -server-id.
  • Optional: -allow-root, -chat-worker, -claude-path.
  • TLS note: use -tls-skip-verify only for self-signed/incomplete certs.
  • Do not mix tokens: never pass TENANT_TOKEN or UI Token to -agent-token.
  • Server ID: keep -server-id unique to avoid conflicts.
4) Connect in web UI
  • Open Sessions in the left sidebar.
  • Go to Workspace Task and create a session first.
  • If no session is created yet, the UI will show no session content (expected behavior).
Windows note (important)
  • Windows currently supports Chat mode only.
  • PTY terminal emulation is not available, so interactive shell sessions are not supported on Windows agents.
  • Use a Linux/macOS agent when terminal-style workflows are required.
