Quick Start

Step 1: Download
# Install cc-agent (Linux / macOS) curl -fsSL https://cc-remote.app/install.sh | bash # Install cc-agent (Windows PowerShell) irm https://cc-remote.app/install.ps1 | iex
Step 2: Connect
cc-agent \
  -control-url wss://YOUR_CONTROL/ws/agent \
  -agent-token <agent-token> \
  -server-id srv-01 \
  -allow-root /path/to/repo \
  -claude-path /path/to/claude
Step 3: Control
Web: Click Open Tenant Panel above to control from browser.
iOS App: https://apps.apple.com/us/app/cc-remote/id6759078097
